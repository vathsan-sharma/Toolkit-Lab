# Backlink strategy (Toolkit Lab)

Goal: earn links from relevant, trustworthy sites so search engines and people find the tools.
Rule: only links that a real editor or user would add. No paid links, link exchanges, comment spam, or fake reviews.

## 1. Free tool directories (week 1)
- Submit to reputable directories that list free online tools, such as AlternativeTo, Product Hunt (when you launch), and local business or library resource lists.
- Write an accurate listing: what each tool does, that files stay on the device, and that it is free.

## 2. Resource and "best free tools" pages (weeks 2 to 6)
- Find blogs and sites that publish lists of free PDF, image or calculator tools.
- Email the author with one specific reason: "Your list of PDF tools does not include a merge tool that works without uploads. Here is ours: [link]."
- Only pitch pages where the tool genuinely fits.

## 3. Broken link outreach (weeks 3 to 8)
- Search for resource pages with dead links to similar tools.
- Tell the site owner about the broken link and suggest the working page as a replacement.

## 4. Helpful answers in communities (ongoing)
- Answer real questions on forums and Q&A sites where the tool solves the problem.
- Link only when it directly answers the question, and follow each community's rules.

## 5. Guides people want to cite (ongoing)
- Our guides with worked examples (for example, the loan payment, age and download time guides) are the kind of pages teachers, blogs and advisers link to.
- Ask education and personal finance sites that already cover these topics to consider them.

## 6. Guest articles (after 3 months)
- Write one useful article for a relevant site with a clear editorial policy, with a link to the matching tool or guide in the body.

## What to track
- Search Console: Links report, monthly.
- Which referring pages send visitors, and which of them still link after a few months.

## What not to do
- Buy links, swap links with unrelated sites, or join link networks.
- Post the same message in many forums at once.
- Ask for links with a generic template that does not mention the page.
